Solution #1 : Recursive, but this code will give you TLE. Basically, to solve DP problems we are going with this approach : Find recursive solution -> do the memoization (DP) -> Top-down approach (DP) :
Time Complexity : Time Complexity : O(2^n), Space Complexity : O(n) :

class Solution {
    public int knapsack(int W, int val[], int wt[]) {
        return findMax(W, val, wt, 0, 0);
        
    }
    public int findMax(int W, int val[], int wt[], int currentMax, int index){
        if(index >= val.length || W <= 0){
            return currentMax;
        }
        
        int ifWeChoose = 0;
        
        if(W-wt[index] >= 0){
            ifWeChoose = findMax(W-wt[index], val, wt, currentMax+val[index], index+1);
        }
        
        int ifWeDoNotChoose = findMax(W, val, wt, currentMax, index+1);
        
        int max = Math.max(ifWeChoose, ifWeDoNotChoose);
        return Math.max(max, currentMax);
    }
}

Solution #2 : Memoization (we need to find the variables that are changing for the length & width of matrix) :
Time Complexity : O(n * W), Space Complexity : O(n * W){for the memoization matix} + O(n) {stack space} 

class Solution {
    int[][] memoization;

    public int knapsack(int W, int val[], int wt[]) {
        memoization = new int[val.length][W + 1];

        for (int i = 0; i < memoization.length; i++) {
            for (int j = 0; j < memoization[0].length; j++) {
                memoization[i][j] = -1;
            }
        }

        return findMax(W, val, wt, 0);
    }

    public int findMax(int W, int val[], int wt[], int index) {

        if (index >= val.length || W == 0) {
            return 0;
        }

        if (memoization[index][W] != -1) {
            return memoization[index][W];
        }

        int ifWeChoose = 0;

        if (wt[index] <= W) {
            ifWeChoose = val[index] + findMax(W - wt[index], val, wt, index + 1);
        }

        int ifWeDoNotChoose = findMax(W, val, wt, index + 1);

        memoization[index][W] = Math.max(ifWeChoose, ifWeDoNotChoose);

        return memoization[index][W];
    }
}

Solution #3 : Top-Down approach (if you see, it is very similar to recersive solution #1) :
Time Complexity : O(n*W), Space Complexity : O(n*W) :

class Solution {
	public int knapsack(int W, int val[], int wt[]) {
		int[][] memoization = new int[val.length + 1][W + 1];
		
		for (int i = 0; i < memoization.length; i++) {
			for (int j = 0; j < memoization[0].length; j++) {
				if (i == 0 || j == 0) {
					memoization[i][j] = 0;
				} else if (wt[i-1] <= j) {
					memoization[i][j] = Math.max(val[i-1]+memoization[i-1][j - wt[i-1]], memoization[i-1][j]);
				} else if (wt[i-1] > j) {
					memoization[i][j] = memoization[i-1][j];
				}
			}
		}
		
		return memoization[val.length][W];
	}
}
